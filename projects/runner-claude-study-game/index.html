Study game

Runner: Claude study game

First released July 2026, last updated September 2026.

A pixel-art side-scroller I built to study for the Claude Certified Architect, Foundations exam. It runs in the browser with no account, and your progress stays on your device.

  • Play Runner ▶
  • View repository ↗

Question terminals sit along each stage. A right answer scores and keeps the streak going. A wrong answer summons a villain and costs a heart. Each act ends in a boss fight. You dodge while its shield is up, then answer the terminal to strike.

It's practice material. A score here won't tell you whether you're ready for the real exam.

Three ways to play

  • Story: six acts of platforming, question terminals and boss encounters.
  • Endless: continuous practice with explanations, streaks and a local score board.
  • Mock exam: timed practice, with results after you submit.

How it's built

  • Phaser and TypeScript, shipped as a static site. Progress stays in the player's browser.
  • The question bank lives apart from the game code. Each question keeps its source attribution and explanation, and the build copies the bank in.
  • The repository started as a compiled game. I recovered the TypeScript source and matched it against that bundle before making any changes.
  • Automated browser checks cover Story, Endless, Mock exam, saved progress, fullscreen and touch controls.
  • GitHub Actions checks the build and publishes to GitHub Pages. A Cloudflare Worker serves it on this domain at /runner/.
  • Light and dark themes, touch controls on phones and support for reduced motion.
