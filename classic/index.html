05 What I believe

Build for the AI that's coming.

Models get better every few months. Whatever I build has to still be worth having when they do.

Build what frontier AI won't replace

Models keep improving at reasoning, writing code and handling formats. None of that tells them what your business has decided is true, or who is accountable for it. That knowledge has to be built, kept and owned, and that's where I put my effort.

Learn each layer by building it

I'm working through AI one layer at a time, from research and governance to deployment, using real research and things I've built. Security goes into each layer as I go.

Governed knowledge

Knowledge is the layer I've worked through most so far. An agent should read knowledge that an accountable person approved, that carries its source, and that expires before it goes stale. Agents propose updates as pull requests, and people review them before anything merges. Each agent only reaches what it's cleared to see.

Stay engine-agnostic

I don't tie a build to one model or vendor. The model is a swappable part, so I use open formats in plain markdown, standard protocols such as MCP, and agent instructions any assistant can read.
