# Solid panels

`panels.webp` (1536 by 1024, six 512 px cells) is the parchment of the core solid's lantern
panels. Built by `tools/build-solid-panels.py` from the six approved ink sketches in
`public/art/sketches/` inked in sepia onto crops of `public/art/sphere/parchment.webp`.
No new art was generated. Rebuild with `uv run --with pillow python tools/build-solid-panels.py`.
